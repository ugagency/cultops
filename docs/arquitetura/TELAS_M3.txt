========================================================================
 MÓDULO 3 (M3 — "Campo") — MAPA DAS TELAS
 Pasta: modulo3/
========================================================================

O M3 cuida da execução em campo das contrapartidas do projeto cultural:
eventos, distribuição de ingressos (Organizações Sociais e Patrocinadores),
lista de convidados, portaria (check-in), evidências e visão gerencial.

Navegação é multi-página: cada tela é um .html real, ligadas por links.
Todas exigem sessão (login) e um projeto selecionado.


------------------------------------------------------------------------
 ENTRADA
------------------------------------------------------------------------

1) index.html  —  Hub "Campo M3"
   Ponto de entrada do módulo. Mostra cards de navegação que levam a
   Eventos, Portaria, App offline (PWA) e Dashboard de contrapartidas.

2) pwa/index.html  —  App PWA "PrestAI Campo"
   Versão offline para uso em campo. Baixa os eventos para o dispositivo
   e permite check-in sem internet ("Eventos disponíveis offline").


------------------------------------------------------------------------
 EVENTOS
------------------------------------------------------------------------

3) eventos.html  —  Lista de eventos
   Lista os eventos culturais do projeto selecionado (cards com status,
   data, local e ingressos). Cada card leva a Editar, Detalhes ou Portaria.
   >> Agora é SÓ listagem (o formulário saiu daqui).

4) evento-form.html  —  Formulário de evento  [NOVO]
   Tela dedicada para criar/editar um evento. 15 campos em 3 blocos:
   Dados (título, tipo, data, horário, status, descrição),
   Local (nome, endereço, cidade, estado, lat/lon) e
   Ingressos (total, cota OS, cota PA).
   - Sem ?id=  -> modo criação (gestor cria o evento).
   - Com ?id=  -> modo edição/preenchimento (operador completa os dados).
   - Botão Excluir fica nesta tela. Ao salvar, volta para a lista.
   >> Substitui o antigo modal que ficava dentro de eventos.html.

5) evento-detalhe.html  —  Detalhe do evento
   Página de um evento específico, com abas de OS, PA e relatório.
   É onde se vinculam Organizações Sociais e Patrocinadores ao evento.


------------------------------------------------------------------------
 DISTRIBUIÇÃO DE INGRESSOS
------------------------------------------------------------------------

6) os.html  —  Organizações Sociais (OS)
   Cadastro e gestão das Organizações Sociais que recebem cotas de
   ingressos do evento.

7) pa.html  —  Patrocinadores (PA)
   Cadastro e gestão dos Patrocinadores / pontos de apoio que recebem
   cotas de ingressos.

8) convidados.html  —  Convidados
   Lista de convidados de um evento: adicionar e gerenciar nomes e o
   status de cada convite.


------------------------------------------------------------------------
 EXECUÇÃO EM CAMPO
------------------------------------------------------------------------

9) portaria.html  —  Portaria
   Check-in / validação de entrada dos convidados no dia do evento.
   Acessada por evento (portaria.html?event_id=...).

10) evidencias-m3.html  —  Evidências
    Upload de fotos/comprovações do evento, usadas na prestação de contas.


------------------------------------------------------------------------
 VISÃO GERENCIAL
------------------------------------------------------------------------

11) contrapartidas.html  —  Dashboard de Contrapartidas
    KPIs, evidências e resumo do projeto — visão consolidada para o gestor.


========================================================================
 FLUXO TÍPICO
========================================================================

 index (hub)
   -> eventos (lista)
        -> evento-form        (criar / preencher dados do evento)
        -> evento-detalhe     (vincular OS / PA, ver relatório)
             -> os / pa / convidados
        -> portaria           (check-in no dia)
             -> evidencias-m3  (registrar fotos/comprovações)
   -> contrapartidas (dashboard gerencial)
   -> pwa (app offline em campo)
